Hilokal JWT Grabber

A small Chrome extension that captures your session cookie from hilokal.com once you're logged in.

Download Extension (.zip)
Chrome doesn't allow one-click installs from outside the Chrome Web Store, so you'll need to follow the 4 quick steps below — it takes under a minute.

Install instructions

  1. Click Download Extension above, then unzip the downloaded file.
  2. Open chrome://extensions in a new Chrome tab.
  3. Turn on Developer mode using the toggle in the top-right corner.
  4. Click Load unpacked and select the unzipped folder.

That's it — the extension icon will appear in your toolbar. Visit hilokal.com, log in, and click the icon to grab your session cookie.
